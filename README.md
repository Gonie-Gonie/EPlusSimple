# EPlusSimple

EPlusSimple is a spreadsheet-based building energy simulation workflow built around EnergyPlus.

The project is designed to reduce the amount of manual EnergyPlus modeling work required for practical retrofit and energy-performance analysis. Instead of editing EnergyPlus input files directly, users prepare structured Excel input files, and EPlusSimple converts them into simulation-ready models, runs EnergyPlus, and summarizes the results.

EPlusSimple currently provides two main entry points:

- **Launcher mode**: a lightweight desktop launcher for Excel-based simulation and debugging.
- **CLI mode**: a command-line executable for scripted workflows.

The project is intended to be portable on Windows. Python, EnergyPlus, Go, and weather data are prepared under the local `runtime/` directory by the setup script, rather than relying on system-wide installations.

## What EPlusSimple does

EPlusSimple provides a simplified workflow for EnergyPlus-based building energy simulation.

In a typical workflow, EPlusSimple:

1. reads structured Excel input files;
2. validates and debugs the input data;
3. converts the input into EnergyPlus-compatible model files;
4. runs EnergyPlus using the local runtime;
5. collects and summarizes simulation results.

This allows users to perform EnergyPlus-based analysis without directly managing detailed EnergyPlus input files for every case.

## Script entrypoint

All project scripts are executed through the root-level dispatcher:

```bat
runscript <command> [args...]
```

Available commands:

```text
setup
build-go
release
```

The dispatcher only selects the target PowerShell script and forwards the remaining arguments as-is.

Mapped scripts:

```text
runscript setup     -> scripts\setup\setup.ps1
runscript build-go  -> scripts\dev\build-go.ps1
runscript release   -> scripts\release\release.ps1
```

Do not run wrapper batch files under `scripts/`. The duplicated batch wrappers have been removed. Use `runscript.bat` from the repository root.

## Setup

Run setup first.

```bat
runscript setup
```

The setup process prepares the local runtime environment required by EPlusSimple.

It installs or configures:

1. **Embedded Python**

   Installed under:

   ```text
   runtime\PythonV3-12-7
   ```

   Python packages are installed from:

   ```text
   scripts\setup\requirements-dev.txt
   ```

   This includes packages needed by the repository runtime and by release-time
   tooling such as the regression document update.

2. **EnergyPlus**

   Installed under:

   ```text
   runtime\EnergyPlusV24-2-0
   ```

3. **Korean TMY weather data**

   Installed under:

   ```text
   runtime\Weather\TMY
   ```

4. **Portable Go SDK**

   Installed under:

   ```text
   runtime\GoV1-26-3
   ```

5. **Repository-local Go cache and module directories**

   Created under:

   ```text
   runtime\.go
   ```

The setup script does not require Python, EnergyPlus, or Go to be installed globally on Windows.

To reset the runtime completely, delete `runtime/` and run setup again.

```bat
runscript setup
```

## Build

After setup, build the executable files using the Go build script.

```bat
runscript build-go
```

For the first build after cloning the repository, or after Go dependency changes, run:

```bat
runscript build-go -Tidy
```

The build script creates the following executable files in the repository root:

```text
EPlusSimpleCLI.exe
EPlusSimpleLauncher.exe
```

These files are generated build artifacts and should not be committed.

## Run

### Launcher mode

Use the desktop launcher for Excel-based workflows.

```bat
EPlusSimpleLauncher.exe
```

The launcher starts the local Python workflow internally and displays the interface through a desktop WebView window. A separate browser window is not required.

Use this mode when you want to upload Excel input files and run the Excel-based simulation or debugging workflow through the graphical interface.

---

### CLI mode

Use the CLI executable for command-line workflows.

```bat
EPlusSimpleCLI.exe
```

To inspect the available commands and options, run:

```bat
EPlusSimpleCLI.exe --help
```

The available command syntax depends on the current CLI implementation.

## Release

Release packaging is also handled through `runscript.bat`.

For a release:

```bat
runscript release
```

To skip documentation and regression tests during packaging checks:

```bat
runscript release -SkipDocs -SkipRegressionTest
```

The release script creates:

```text
dist\EPlusSimple_V<version>\
dist\EPlusSimple_V<version>.zip
```

The release Python runtime is created fresh under the release directory and
installs only:

```text
scripts\release\requirements-release.txt
```

Regression document updates run with the repository runtime prepared by setup,
not with the released Python runtime.

EnergyPlus runtime pruning is defined by:

```text
scripts\release\energyplus-release-prune.txt
```

The release package includes:

```text
EPlusSimpleCLI.exe
EPlusSimpleLauncher.exe
runtime\PythonV3-12-7\
runtime\EnergyPlusV24-2-0\
runtime\Weather\TMY\
src\
examples\
docs\       # when documentation build is enabled
```

The release package does not include setup download caches or temporary extraction directories.

## Notes for developers

### Runtime isolation

EPlusSimple uses the embedded Python runtime under:

```text
runtime\PythonV3-12-7
```

Python packages should be installed into this runtime, not into the user-level Python environment.

To check that packages are imported from the runtime Python:

```bat
runtime\PythonV3-12-7\python.exe -s -c "import importlib; mods=['pandas','numpy','tqdm','openpyxl','jinja2']; [print(m, importlib.import_module(m).__file__) for m in mods]"
```

The printed paths should point to:

```text
runtime\PythonV3-12-7\Lib\site-packages
```

They should not point to a user-level path such as:

```text
C:\Users\<user>\AppData\Roaming\Python\Python312\site-packages
```

---

### Weather data

Korean TMY weather files are prepared by setup under:

```text
runtime\Weather\TMY
```

The release package also includes this directory.

To check the installed weather files:

```bat
dir runtime\Weather\TMY
```

---

### Re-running setup

If dependencies are missing or the runtime environment is corrupted, rerun:

```bat
runscript setup
```

For a full reset:

```bat
rmdir /s /q runtime
runscript setup
```

---

### Rebuilding Go executables

If Go source code is changed, rebuild:

```bat
runscript build-go
```

If `go.mod` or `go.sum` is changed, rebuild with tidy:

```bat
runscript build-go -Tidy
```

---

### Running release checks

A full release runs the configured release steps, including regression and documentation unless skipped.

```bat
runscript release
```

To test only the packaging flow:

```bat
runscript release -SkipDocs -SkipRegressionTest
```
