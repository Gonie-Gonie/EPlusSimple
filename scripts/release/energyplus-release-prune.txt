# EPlusSimple EnergyPlus release pruning specification.
#
# Base path:
#   runtime\EnergyPlusV24-2-0 inside the release package.
#
# Syntax:
#   require <relative-file-path>
#   prune   <relative-path-or-glob>
#
# Notes:
#   - Blank lines and lines starting with # are ignored.
#   - Forward slashes and backslashes are both accepted.
#   - Lines without a command are treated as prune entries.
#   - Root DLLs are intentionally kept unless each one is tested.
#   - PostProcess\ReadVarsESO.exe is required while src\idragon\launcher.py
#     passes the EnergyPlus -r flag.
