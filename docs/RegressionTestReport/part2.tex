\chapter{대상건물}

\section{ASHRAE 140-modified}
\label{section:targetbuilding-ashrae140-modified}

이 모델은 ASHRAE Standard 140-2023(Method of Test for Evaluating Building Performance Simulation Software)의 Base Case 600을 \simulator 의 입력에 맞게 일부 수정한 것이다\cite{ASHRAE140_2023}. 이는 남측 벽면에 총 $12m^2$($6m^2$ 창호 2개소)의 투명 이중창이 있는 $8m \times 6m \times 2.7m$ 크기의 직육면체 형태의 단일 존 건물이다 \parencref{fig:ashrae140-2023-case600shape}.

\begin{defaultfigure}
  \includegraphics[width=0.6\textwidth]{ANSI-ASHRAE-140-2011-Case-600-900_W640.jpg}
  \caption{ASHRAE Standard 140에서 제시된 Case 600 건물 \cite{riquelme2019validation}}
  \label{fig:ashrae140-2023-case600shape}
\end{defaultfigure}

ASHRAE Standard 140-2023에서 변경된 내용은 아래와 같다.
\begin{itemize}
  \item 소규모사무실 용도프로필 사용
  \item 냉난방 COP 3.0의 전기히트펌프 사용
  \item 조명밀도는 $10W/m^2$, 침기율은 $1.5ACH_{50}$
\end{itemize}
