\chapter{목적}

회귀검증(regression testing)은 소프트웨어나 시뮬레이션 엔진이 업데이트, 기능 확장, 코드 구조 변경 등을 거친 이후에도 기존 기능이 동일한 입력 조건에서 일관된 결과를 재현하는지 점검하는 핵심 품질관리 절차이다 \cite{sommerville2015software}.
건물 에너지 시뮬레이션 엔진은 열수지 모델, HVAC 계산 루틴, 일정 스케줄, 기상데이터 처리 등 복수의 모듈이 상호 의존적으로 작동하기 때문에, 작은 코드 변경만으로도 출력값이 예기치 않게 변동할 수 있다.
이 때문에 EnergyPlus와 같은 국제 표준 건물에너지 엔진에서도 버전 개발 과정에서 표준 테스트 파일을 이용한 자동 회귀검증 시스템을 운영하여, 새로운 릴리스가 기존 물리 모델의 동작을 유지하고 있는지 정기적으로 확인한다 \cite{EnergyPlusValidation}\cite{EnergyPlusRegressionTool}.
이러한 절차는 엔진의 계산 신뢰성, 수치적 안정성, 재현성을 장기적으로 보장하며, 신규 엔진 개발 시에도 동일한 회귀검증 전략을 적용하는 것이 권장된다.
